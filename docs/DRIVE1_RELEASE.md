# DRIVE1 — 單人試駕（2026-11-11）

第一階段把既有參觀地圖變成可駕駛的原型。保留原有地圖、配色、夜景、維修區預設視角及非官方概念聲明；首頁新增「單人試駕」。此版沒有多人連線，也不是正式 F1 模擬器。

## 操作

- 電腦：W／↑ 加速，S／↓／空白鍵煞車，A、D／左右方向鍵轉向。
- 手機：按住左右鍵與油門／煞車，可同時按兩個按鈕。
- R 回到附近賽道中心，P 暫停／繼續，Esc 返回參觀；亦有畫面按鈕。
- 追車鏡頭、車速、目前圈速、上一圈與本次頁面工作階段最佳圈速。
- 24 個依序通過的隱藏檢查點驗證完整一圈；碰撞、使用救援或暫停會使當圈不計成績。下次通過終點重新計時。
- 切換視窗或將網頁移到背景會自動暫停，避免油門卡住。

## 實作

`driving.js` 使用獨立的 60 Hz 固定步進操控及賽道邊界碰撞，沿用 CircuitLayout 的實際路線與變化路寬。大幅延遲的單幀最多模擬 250 ms；圈速為模擬時間，還不適合遠端競賽排行榜。

`drive-ui.js` 管理輸入、HUD 與追車鏡頭；`driving.css` 處理桌機、直式及橫式觸控版面。`index.html` 切換參觀／試駕及渲染玩家車。

試駕時暫停原本展示車流，只保留玩家車；玩家車採 1 倍道路尺度，參觀車流維持原本的 3 倍展示大小。夜景／日景沿用進入試駕前的選擇。
