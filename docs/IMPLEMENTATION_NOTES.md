# 接手修正紀錄 — 2026-10-08

沿用交接版單檔自製 WebGL 與 Canvas 2D 備援。沒有引入第三方 JavaScript、地圖 API 或外部素材依賴。

## 本次修正

- 雙指事件以每次事件前的兩個觸點快照計算，避免重複套用另一指的舊位移；WebGL 與備援皆修正。
- 鍵盤縮放加入距離限制，避免縮到上限後要按多次才能返回。
- 相機匹配場景東／北座標與小地圖；正上方視角東在右、北在上。同步修正拖曳、平移及指北針。
- 手機調整相機視野，控制按鈕至少 44px，視角排列成兩列；加入橫向與安全區排版。
- 加入明確非官方概念標示、切換狀態、鍵盤焦點樣式及縮放按鈕名稱。
- WebGL 建立失敗沿用 2D 備援；著色器初始化失敗改用新畫布啟動備援。失去 WebGL context 顯示重新載入入口。
- `?renderer=2d` 可手動使用備援，也供重現測試。備援不等同 WebGL 品質與效能。
- 保留原有概念路線；主場景與小地圖使用各渲染器相同路線點，約 5.44 km 是幾何估計，非實測。

## 地理核對與限制

民航局 [RCSS AIP 2023-02-23 存檔](https://ais.caa.gov.tw/eaip/AIRAC%20AIP%20AMDT%2001-23_2023_02_23/eAIP/RC-AD%202%20RCSS%20%E8%87%BA%E5%8C%97-%E6%9D%BE%E5%B1%B1TAIPEI-SONGSHAN-zh-TW.html) 列出跑道 2,605 × 60 m，10 跑道真方位 092.22°，參考點 25°04′11″N、121°33′09″E。模型以近似東西軸示意，未旋轉校正約 2.22°，不供航務用途。

模型座標 x+ 為東、z+ 為北；河流在 z+、航廈在 z-、101 在 x+/z-。101 地址核對 [台北101官方網站](https://www.taipei-101.com.tw/zh/) 的信義路五段7號。河岸曲線、橋梁、街廓、航廈量體與地標間距仍是程序化近似，未導入測量資料、OSM 建物輪廓或 DEM，不能稱為地理精準模型。

預設仰角保留交接版 1.01 rad（約 58°）；原始概念渲染沒有相機參數，無法客觀驗證「比海報多俯瞰 20%」。正上方仍是接近垂直的透視投影，UI 已移除錯誤的 ORTHOGRAPHIC 字樣。

本輪完成可靠性與方位顯示修正；寫實材質、真實航廈建模、河岸與都市量體改善仍屬後續工作。原始參考圖保留在本機 `references/`，不隨公開程式提交，避免把含虛構賽期／官方風格標誌的海報當成公開賽事素材。
