# E1 景觀與賽事設施更新（2026-10-12）

保留現有 UI、配色、互動功能與非官方概念聲明。

- TAIPEI 屋頂字樣改成貼合弧形屋面，移除高架支撐造成的懸浮感。
- 內場樹木由 80 棵增至 320 棵（增加 300%），六種樹形，高度為原先五倍；此為刻意放大的視覺比例。
- 五架飛機尺寸加倍，重新排列並檢查航廈、空橋、賽道與相互間距。
- 偏遠看台移近賽道，保留面向賽道的階梯座席及主看台。
- 移除舊看台遺留的青色長方形燈框。
- 加入面積大於 PADDOCK 的連續多峰山坡，邊界緩降回草地。
- 新增沿線護欄、網索及 TAIPEI 看板，保留維修道與緩衝區開口。這些是概念視覺設施，並非 FIA 認證或工程合規宣稱。
- PADDOCK 黑色面板改成原創動態賽事模擬畫面，與站內賽車位置同步，不是外部賽事直播。
- 河岸路寬加倍，與其他區段漸變銜接；為避免侵入水面，局部路線向南平滑退讓，最大約 14 公尺。新長度由共同幾何自動重算，約 7.402 公里。
