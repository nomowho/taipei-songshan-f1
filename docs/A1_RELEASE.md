- 沿用既有 WebGL、OSM 城市、材質、日夜景、TAIPEI 流線屋頂與深色 HUD。
- `circuit.js` 統一 3D、2D 備援、小地圖、動畫、預設視角與統計；735 個核准控制點，細分為 2,205 個取樣點。長度由取樣自動計算為約 5,732.66 m。
- 17 彎：東端 R20 m 髮夾、北側河岸連續彎、西側低速技術區。主直線約 1,850 m；保留跑道作為場地基準，真實跑道長度仍標 2,605 m。
- 主髮夾外側看台、東端柏油逃生區及西側碎石／柏油緩衝面。移走舊北側看台與阻擋新路線的大型構件。
- Pit Lane 492.3 m、11 隊車庫及停放車、1 預備庫、22 個發車格。沿用使用者指定 3 倍車體顯示比例。
- 可放大的小地圖：T1–T17、三個 Sector、起終點、測速點、Straight Mode 區段。最窄手機縮圖僅保留四個彎號，點圖展開可看全部。
- 美麗華：雙輪圈、輻條、A 字支架、48 座艙、彩色夜間燈圈。圓山飯店：14 層陽台、紅柱金瓦曲面屋頂、入口及側翼屋頂、概念山坡。依公開地理位置放置，排除重複 OSM 主建物。來源與近似範圍見 [LANDMARKS.md](LANDMARKS.md)。
- 七個場景視角及 3D 車載一圈。移動、縮放、方向鍵、切換場景或環繞會退出車載模式；2D 備援停用車載按鈕。
- 夜賽說明保留為氣候與賽程概念，4 月鈴鹿東亞連站僅屬提案；非官方概念聲明全程保留。

## 取捨與數值解讀

- 使用 54 圈，約 309.56 km；依使用者原先四捨五入公式會得到 53 圈／303.83 km，未達 305 km。採第一個超過 305 km 的整圈數。
- 最高 330 km/h 與 1:40–1:55 為概念目標；簡化曲率、加速及煞車模型的動畫圈速約 107.5 秒，不是車輛動力模擬結果或安全認證。
- 一般路面 12–15 m。為容納 3 倍展示車及 22 格，起跑區局部拓寬至 24 m；車體與賽道工程比例無法同時完全真實。
- 逃生區材質和幾何已呈現；不宣稱 FIA Grade 1。需專業碰撞、煞車、地質、淨空與機場停航評估才能判斷工程可行性。
- 保留長形既有主建築與 TAIPEI 屋頂，車隊實際使用區縮至中段；其餘量體作概念接待空間。
- 2D 備援保留相同路線與地標幾何，材質和車輛動畫較簡化。摩天輪座艙目前靜態。

- `node --test tests/*.test.cjs`：29 項通過（路線閉合與長度、17 彎、22 格、維修道長度、無中心線自交、航廈淨距、彎道減速、地標幾何與座艙、光照法線、OSM、車體接地、材質、雙指輸入、iOS framebuffer）。
