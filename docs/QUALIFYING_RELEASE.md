# 排位賽與共用前五名排行榜

2026-11-11。原「單人試駕」入口改為「排位賽」，輸入車手名字並連線成功後開始。保留原車體尺寸、追車視角、平滑化、加速與三段計時；護欄碰撞只減速，不取消成績。

## 排名

- 名字與最快有效單圈公開顯示，所有裝置共用同一份雲端資料。
- 去除名字前後空白、合併連續空白、正規化全形文字；大小寫不區分。每個名字只保留一筆最快有效圈速，較慢或相同成績不覆蓋。
- 側邊顯示前 5 名，按圈速排序；同圈速以紀錄時間、名字排序。每 15 秒重新讀取，成功上傳也會立即更新。
- 名字為 1～20 個字。同名視為同一車手，不是帳號或身分驗證；輸入畫面會提醒使用固定暱稱。
- 賽道版本獨立排行，避免不同路線或速度規則混比。

## 成績流程

沿用駕駛核心：必須完整通過 24 個檢查點、三段有效並順向完圈，才送出成績。救援、暫停或其他原有無效判定不會送上排行榜。護欄碰撞仍可計時與排名。

雲端以短效排位賽識別授權提交，驗證路線版本、圈次順序、最短合理時間、三段合計及已經過的時間。同一提交可安全重試；資料庫以唯一名字及條件更新保留最快成績。網路延遲不會消耗下一圈的有效計時額度。

上傳失敗會顯示「尚未上傳」與重試按鈕，並在網頁仍開啟時自動重試。尚未送達的資料只暫存在頁面記憶體；關閉或重新整理前請確認「成績已同步」。登入服務失效時需重新進入排位賽。

此為朋友間使用的概念遊戲排行榜，沒有驗證真實身分或完整伺服器重演物理，因此不宣稱具備競技級防作弊。三段顏色仍依介面標示比較本機歷史與本次成績，與雲端最快單圈排名分開。
