# C1 航廈與河岸新配置 — 2026-10-11

## 完成內容

- 依使用者附圖重新構成航廈側主直線、東端雙折返、河岸 S 彎與西側回程。3D、2D 備援、動畫賽車及小地圖均讀取同一份 circuit.js。
- 新路線約 **7.411 km、22 彎、42 圈**。路寬約 **16.5–40 m**，直線、發車區、重煞區與技術彎平順漸變。
- 移除機場至基隆河南岸之間的道路，包含穿越清除區的長路段、高架及路肩；保留河面與對岸路網。新增觀賽綠地依河道偏移輪廓裁切，東側止於河流轉彎之前。
- 維修區隨主直線移至東南側；保留 492 m 維修道、11 車隊車庫與停放賽車、22 個起跑格。縮短兩側接待空間以避開東端折返，保留曲面金屬屋頂及 TAIPEI 字樣。
- 新增金屬起跑燈架與五組成對紅燈、20 面原創 F1／TAIPEI／GP 賽事字牌、166 位維修技師及工作人員。
- 保留日夜景、單指平移、雙指平移縮放、全區／維修區／車載視角、美麗華及圓山 5 倍展示模型、6 座看台與4處觀賽坡，以及非官方概念聲明。

## 取捨與限制

- 本次以使用者新附圖的輪廓及河岸／航廈延伸為優先，因此超出先前 5.0–5.8 km、16–18 彎建議。附圖重複彎號改成依行駛順序編號 T1–T22，沒有照抄錯號。
- 原跑道中心線不再是整條賽道的主直線；起終點、維修道與車庫已一起對齊新的南側主直線。
- 簡化速度模型約 142 秒／圈；頁面以 2:15–2:30 作概念範圍。不是性能或 FIA 安全認證。
- 起跑燈目前是五組紅燈展示，未加入完整起跑倒數或整排賽車同步起步的模擬。
- 河岸道路移除、綠地擴建、地標比例均屬概念改建，不代表現況或工程可行性。
- iPhone Safari 真機殘影與效能仍須實體裝置驗證。
