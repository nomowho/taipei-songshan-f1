# 三張自訂賽道看板（2026-11-11）

- 使用使用者提供的三張 PNG 原圖，保留文字、內容與長寬比。素材位於 `assets/billboards/`。
- 主直線後段附近：遠見旅行箱畫面、台北競速畫面。河岸回程：綠色通勤畫面。
- 替換三個既有大型看板，其中原航廈側的一面移到河岸回程；雙面貼圖分別設定方向，避免背面文字鏡像。支架在賽道外，板面朝向車輛接近的方向。
- `circuit-billboards.js` 共用配置與幾何，WebGL 與 2D 備援都可顯示原圖。WebGL 重用既有材質插槽，沒有增加硬體所需的 texture unit 數量。
- 保留網站的非官方概念設計聲明。看板圖片是使用者提供的場景素材，不代表人物、品牌或賽事方實際參與或贊助。
- 同時修正排位賽名字視窗開啟時的背景繪圖負擔：暫停 3D 重繪，待輸入完成後恢復；雲端請求逾時上限改為 30 秒。

驗證：看板比例／雙面文字方向、賽道淨空、駕駛與分段計分測試；瀏覽器車載畫面、真實雲端排位賽連線、手機版面及公開部署檢查結果另存工作區 QA 紀錄。未進行 iPhone Safari 實機測試。
