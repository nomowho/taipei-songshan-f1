# B1 操作與觀賽空間更新 — 2026-10-09

## 使用者七項要求

1. 主畫面增加「平移」切換：開啟後左鍵／單指拖曳平移；關閉回到旋轉。雙指平移與縮放、右鍵平移保留。3D 及 2D 備援一致。
2. 美麗華與圓山完整模型放大 5 倍，以各自地理中心及 y=-8 為基準，包含摩天輪底座、飯店屋頂與山坡。標籤同步提高，移除放大範圍內重複的 OSM 街屋。這是展示比例。
3. 賽道路面寬度為前版的 2 倍：一般 24–30 m，起跑展示區 48 m；Pit Lane 保留 13 m。
4. 北側 S 彎起伏加深，最北中心線 z≈317.4。新增 6 座分層金屬頂看台、4 座有機綠色觀賽坡與低面數觀眾。完整 footprint 避讓路面、緩衝區、河岸及保留的 OSM 道路，包括高架道路。
5. 清除賽道北側至實際基隆河南岸之間的 OSM 建物，保留河對岸城市；排除與新觀賽區重疊的舊廣告柱、旗幟及燈柱。
6. 刪除西側、東側、河岸、美麗華、圓山五個視角按鈕，只保留全區俯瞰、維修區及車載一圈。
7. 刪除航廈周圍原有 24 台機場勤務小車，保留 PIT 停放賽車與賽道動畫賽車。

## 數值與取捨

- 同一份 `circuit.js` 驅動 3D、2D 備援及小地圖。新路線約 **5.896 km / 17 彎**，依超過 305 km 的整圈數重算 **52 圈**。
- 路線較前版建議上限 5.8 km 多約 96 m，以容納這次要求的更深 S 彎。主直線及 R20 m 東端髮夾保留。
- 簡化動畫速度曲線約 117.6 秒／圈，UI 目標 **1:50–2:05**；不作車輛動力學或安全認證。
- 北側看台受實際高架道路與河岸限制，分散至可用空間，而非沿河排成一直線。東側新增看台放在主直線南側。
- 地標 5 倍、賽車 3 倍均為使用者指定展示比例；不代表真實建築／車輛尺度。
- 視覺風格、OSM 城市底圖、TAIPEI 曲面屋頂、日夜景與「非官方概念設計」聲明保留。

## 驗證

- 自動測試：`node --test tests/*.test.cjs`，41 項通過。
- 涵蓋單指平移不改變旋轉／縮放、雙指位移、精確 5 倍地標幾何、路寬／閉合／長度、航廈淨距、看台與實際 OSM 道路／河岸／緩衝區淨距、材質法線與備援共用模型。
- 實際場景建立與低位物件道路淨距檢查通過；內嵌 JavaScript 語法通過。
- Chromium 實際載入 WebGL 及 2D 備援，測試平移切換、拖曳、日夜與全區視角；320／360／390 px 手機版面控制項皆在畫面範圍內，沒有 JavaScript 或 console 錯誤。
- 2D 備援加入靜止畫面快取；相機、視窗尺寸或顯示設定改變時才重畫，避免持續排序繪製完整城市。
- 實體 iPhone Safari 殘影與效能仍需真機驗證。公開部署另以 Pages 建置狀態與匿名 HTTP／瀏覽器確認。

部署須包含新增的 `circuit-spectators.js`，與其餘根目錄 JavaScript 及 `data/taipei-map.js` 一同發布。
