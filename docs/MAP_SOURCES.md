## 材質與品牌

- 移除屋頂實體重複肋條、金屬貼圖條紋與屋頂網格。金屬採低粗糙度高光、視角 Fresnel 與天空色反射近似；不是鏡面環境探針或光線追蹤。
- 保留玻璃帷幕、TAIPEI 字樣、夜間屋緣燈條及先前放大三倍的車輛。
- Pirelli、DHL、Lenovo 的 F1 合作關係查證於 [Formula 1 官方合作夥伴頁](https://www.formula1.com/en/information/formula-1-partners.2shz7bIVhGgS3ovP69N3Rs)。新增品牌名稱與配色看板，以及有輕微飄動效果的旗幟；使用自行排版文字，未下載官方標誌圖檔。
- 場內看板標示 CONCEPT DISPLAY，頁面說明品牌不是本虛構賽事的贊助商。品牌名稱及相關權利屬原權利人。

## 驗證與限制

- 既有手勢、縮放、方位、材質與 iOS 相容路徑測試；新增實際道路名稱、建物屋頂三角化覆蓋與高度來源、地圖投影測試。
- 地圖資料與品牌貼圖隨網站載入，不依賴即時第三方地圖 API 或金鑰。
- iPhone Safari 真機的殘影仍需原裝置確認；桌面或相容模式測試不代表真機 GPU 驗收。

- 本次 15 項自動測試通過；隔離的 Chromium 軟體 WebGL 測試正常顯示 LIVE 3D、日夜模式與手機相容模式，無 JavaScript 錯誤。2D 備援亦驗證載入。內建瀏覽器連線逾時，改以獨立、無登入的測試瀏覽器驗證；未聲稱實機 FPS。
