# 建築與材質更新 — 2026-10-08

沿用既有 WebGL 引擎、相機、概念賽道和 2D 備援，新增本機 `materials.js`。沒有下載照片、第三方模型或外部材質，無額外授權及網路請求。

## 已實作

- 住宅磁磚、窗框、樓層帶、屋簷；玻璃大樓的視角反光及日夜窗燈。
- 更密集且高度不同的概念街廓、人行鋪面、屋頂女兒牆、樓梯間、水塔、冷氣機與部分太陽能板。
- 航廈金屬屋頂肋條、設備、立面分格；維修區車庫門、遮簷與通風設備；機場勤務車輛。
- 瀝青細粒、水泥板縫、草地、金屬、屋頂與磁磚紋理；樹幹和雙層立體樹冠；動態河面波紋及視角反射。
- 修正原有地面、屋頂及建築外牆朝內的法線。加入方向光、半球環境光、地面接觸暗部、霧與建物投影。

## 資源與相容性

原創程序材質先由固定雜訊產生，再取出七張 128×128 貼圖；各自使用重複取樣及 mipmaps，避免圖集接縫造成格線。七個材質取樣器加一個陰影取樣器，共八個，符合 WebGL 1 最低取樣器數量。

陰影使用桌機 2048、窄螢幕 1024 的靜態深度圖，只於首次載入或建物顯示切換時重建。陰影初始化失敗可保留材質模式。小型屋頂細節只在機場周圍的建物生成；沒有引入大型照片或模型下載。

## 驗證

`node --test tests/*.test.cjs`：10 項通過，涵蓋既有滑鼠／合成雙指手勢、縮放邊界、東南方位，以及地面／外牆／樹冠法線、貼圖確定性與不透明度。

本機 Chromium 已實際顯示 LIVE 3D，檢視日景、夜景、維修區及城市近景；材質接縫問題已於視覺檢查後修正。所有預設視角皆可切換，旋轉與滾輪操作沒有產生 console error / warning；建築切換後陰影正常重建；`?renderer=2d` 仍顯示備援畫面。

手機模擬 390×844（實測約 391×844 CSS px）仍顯示 LIVE 3D，13 個主要控制按鈕均在視窗內且高度約 44px。已留存城市日／夜景及手機截圖；這不等於真機測試。

## 屋頂 TAIPEI 字樣追加

依使用者提供的賽道建築參考圖，在維修區主建築西側屋頂加入大型 TAIPEI 幾何立體字，白色發光字面、紅色外緣、深色支架。字樣是場景模型的一部分，隨相機旋轉且參與投影；2D 備援也使用相同字形的簡化屋頂版本。維修區預設相機微調為完整呈現字樣的取景。未使用參考圖中的商標或照片素材。

## 仍有的限制

這是更有材質與建築細節的概念沙盤，未使用實測建物輪廓、攝影測量或照片級 PBR 素材。反射為著色器近似，沒有即時反射周圍物件；2D 備援維持原有簡化畫面。

未實測 iOS／Android 真機手勢、FPS、低階 GPU 或陰影失敗故障注入；不能以桌機視窗模擬代表上述驗收。場景仍保留「非官方概念設計」標示。
