# D1 場館配置更新（2026-10-11）

維持 C1 賽道形狀、7.411 公里、22 彎與現有 UI；此頁為非官方概念設計。

- 航廈前加入三架 Boeing 風格大型雙引擎客機、兩架台灣 F-16V 風格戰機；幾何模型為造型示意。
- 重新設計七座面向實際賽道的看台，其中 PADDOCK 對面主看台長 520 公尺；使用三種金屬頂棚設計，座席向後升高。
- 內場六座大小不同的草坡、80 棵樹，避開賽道、維修道、建物、河面與保留道路。
- 河面增加五艘船艇，包含遊艇、帆船、小艇與河上客船。
- Pit Lane 改成平順分流／匯流曲線，路面等高，護欄與路緣配合開口；保留十一隊車庫。因進出口轉折拉順，總長約 545 公尺，較原先 400～500 公尺的建議稍長。
- 起跑架雙面皆顯示由左至右的 TAIPEI；維持五組雙紅燈。

## 驗證

部署前檢查桌機 WebGL、390×844 手機尺寸、2D 備援、平移、鍵盤旋轉、縮放、日夜切換及維修區視角。手機尺寸的所有控制項皆位於可見範圍，瀏覽器未出現錯誤或警告。

`node --test --test-concurrency=1 tests/*.test.cjs`：60／60 通過。獨立審查指出的舊看台殘留與飛機起落架埋入地坪問題已修正，限定範圍複查通過，沒有未處理的 P1／P2。

公開部署結果於完成驗證後補記。

## 限制

飛機與船艇為靜態概念模型；起跑燈尚未加入倒數。尚未使用實體 iPhone Safari 複測效能及殘影。建築／交通安排不代表實際營運或工程認證。
