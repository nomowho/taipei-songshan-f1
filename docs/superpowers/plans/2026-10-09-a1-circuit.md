# A1 Circuit Implementation Plan

> Execute task by task; use subagent-driven-development for isolated landmark geometry and review. Existing user authorization covers implementation and publishing to nomowho/taipei-songshan-f1.

**Goal:** Implement the approved 5.733 km / 17-turn A1 circuit, compact 2026 paddock, Miramar wheel and Grand Hotel while retaining the site's visual identity.
**Architecture:** circuit.js owns route, arc lengths, turns, pits, presets and schematic. circuit-scene.js builds the same physical layout through a mesh adapter in both renderers. landmarks.js owns reusable landmark geometry, with the same adapter for fallback. Keep the WebGL shader/OSM renderer and existing input handlers.
**Tech Stack:** static HTML/JavaScript, custom WebGL, Canvas2D, node:test.
**Spec:** ../circuit-proposal/REVIEW.md and layout-draft.json (sibling of this repository under outputs).
