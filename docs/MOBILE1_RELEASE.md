# 手機排位賽視野與操作（2026-11-12）

- 手機預設收起 TOP 5 與詳細分段計時，改成工具列的「成績」切換及 S1／S2／S3 色條；桌機保留完整資訊。
- 一般行駛中的檢查點提示收起；碰撞、逆向、無效圈、暫停與起跑提示仍顯示。橫式精簡底部儀表，保留速度和目前圈速。
- 觸控裝置預設自動油門。先按「起跑」才加速；之後左手方向鍵、右手大型煞車鍵，煞車切斷油門，放開後再加速。
- 「自動油門／手動油門」可隨時切換，記住此瀏覽器的選擇。手動模式須持續按油門；兩種模式都以煞車優先。
- 暫停、救援、重開、切換油門模式、離開排位賽會清除輸入與自動加速狀態。繼續排位賽後須再按「加速」；觸控取消時暫停，避免殘留操作。
- 成績收合只改變顯示，不影響計時或上傳；既有護欄碰撞有效、暫停／救援無效等規則保留。
- 遠見旅行箱看板移到河岸回程，綠色通勤看板移到原遠見的主直線位置。圖片比例與雙面文字方向保留。
